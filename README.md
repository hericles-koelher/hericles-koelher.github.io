# Hericles Koelher — Website

A personal website introducing Hericles Koelher's web development services.

**Live website:** [hericles-koelher.github.io](https://hericles-koelher.github.io/)

## Built with

- [Astro](https://astro.build/)
- [Tailwind CSS](https://tailwindcss.com/)

## Run locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

The production site is deployed to GitHub Pages. Pushing to `main` runs the deployment workflow in `.github/workflows/deploy.yml`.
